# Research Documents

保存可審查、可回溯的正式研究報告。命名為 `OVR-<TYPE>-NNNN-short-topic.md`，既有研究類型為 REPO、INV、VER、ADR。Experiment 紀錄放在 `experiments/`，PRD / Technical Design 放在 `docs/specs/`，Coding Agent Handoff 放在 `docs/handoffs/`。

重要主張要有固定 upstream ref、Evidence label 和 validation state；首次探索不必製作正式文件。先搜尋相關 artifact 並避免重複。
