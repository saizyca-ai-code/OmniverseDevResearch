# Coding Agent Handoffs

在 L4（Implementation Handoff）期間保存大型實作的交接工作包（`OVR-HOF-NNNN`，type=`handoff`）。從 `templates/development-handoff.md` 建立。

Handoff 必須指定獨立 implementation repo、工作分支／ref、可改動路徑、來源 PRD / Technical Design / ADR、驗收測試和阻礙。Upstream 與研究 repository 不因交接而自動獲得寫入授權。完成開發後回寫的應是關鍵設計落差、實驗事實和可重現證據，而非全部 Coding Agent 日誌。
