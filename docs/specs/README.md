# Product & Technical Specifications

在 L3（Solution Design）期間保存影響正式開發的 PRD (`OVR-PRD-NNNN`，type=`prd`) 與 Technical Design (`OVR-DES-NNNN`，type=`technical-design`)。模板分別位於 `templates/product-requirements.md` 和 `templates/technical-design.md`。

PRD 定義要達到什麼目的、功能範圍、驗收指標；Technical Design 定義如何做、資料流、API 契約、風險及測試。應連結 Investigation / ADR 和具版本釘選的來源，不要把未證實假設寫成已實現的產品能力。
