# Research Status Lifecycle

Use one of these status values in document front matter:

- planned — scoped, but substantive investigation has not started.
- in-progress — active investigation or writing.
- review — ready for technical or editorial review.
- verified — evidence and validation have been reviewed; specify the exact validation performed in the report.
- stale — source versions or assumptions require review before reuse.
- superseded — replaced by a newer report; link the replacement.
- accepted — a decision record has been accepted.

The status is a workflow label, not a substitute for the evidence and validation fields in the report.
